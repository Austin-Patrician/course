今天最重要的一页

聊天框 和 干活工具,是两回事

聊天框
你问,它答
它给你文字,复制粘贴还得你自己来
干活工具
你交代,它动手
它自己读文件、改文件、跑命令、看结果
差别
顾问 vs 实习生
一个只出主意,一个真的把活干完
【核心区分 · 25 秒】 这一页是全集的重点。 聊天框:它给你一段文字,剩下的活还得你自己干。 干活工具:你说一句,它自己去读文件、改文件、跑命令、看结果,不行再改。 一个像顾问,一个像实习生。今天讲的五个,全是后者。

Codex

OpenAI 出品

OpenAI 自己的编程 agent,一个产品四种用法

终端 桌面 App 云端 IDE 插件
【Codex · 20 秒】 第一个,OpenAI 的 Codex。 它不是一个软件,而是一条产品线,四种用法:终端、桌面 App、云端、IDE 插件。 左边这个终端就是最常用的形态 —— 你打一句中文,它自己改文件、跑测试。
Codex

它能干什么

01
读懂整个项目
不是只看你打开的那个文件,而是把整个仓库读一遍
02
自己动手改
直接改文件、装依赖、跑测试,不是给你建议让你抄
03
并行跑长任务
云端可以同时开好几个,你在忙别的它也继续干
适合谁 已经在用 ChatGPT 订阅的人;要把长任务丢到云端并行跑的人
注意 能换成别家的模型,但对方必须支持 Responses 接口
【Codex 能力 · 20 秒】 三件事:读懂整个项目、自己动手改、还能并行跑长任务。 适合两种人:已经在付 ChatGPT 订阅的,和习惯在终端里干活的人。 要提醒一句:它也能接别家的模型,但有门槛 —— 要求对方实现 Responses 接口,只兼容普通接口的不行。

Claude
Code

Anthropic 出品

终端里最出名的那个编程 agent

终端 IDE 插件 桌面 App 云端会话
【Claude Code · 20 秒】 第二个,Anthropic 的 Claude Code。 它和 Codex 很像,也是终端里的编程 agent,但走的是另一条路线。 右边这四步是它的工作循环:读懂代码库、跨文件改、跑测试、没过就再改。
Claude Code

它强在哪里

01
仓库级改造
一次动几十个文件的活,它比聊天框可靠得多
02
会自己验证
改完自己跑测试,失败了继续改,不用你盯着
03
分工可指定模型
同一个任务里,能让不同的小 agent 用不同的模型
适合谁 要动很多文件的改造;对代码质量要求高的人
注意 要 Claude 的订阅或 API 额度,没有免费档
【Claude Code 能力 · 20 秒】 它最强的三点:仓库级的大改造、改完自己验证、还能给不同的小 agent 指定不同模型。 适合要动很多文件、又在意代码质量的人。 注意它要付费,没有独立免费档。

Trae

字节跳动出品

一个把 AI 装进编辑器的完整开发环境

桌面 IDE 中文优先 也有网页版
【Trae · 20 秒】 第三个,字节跳动的 Trae。 它不是终端工具,是一个完整的编辑器 —— 左边文件树、中间代码、右边 AI 对话。 对中文用户特别友好,你直接用中文描述需求,它能从零搭出一个项目。
Trae

它适合什么场景

01
从零建项目
一句话描述需求,它把文件、代码、页面全搭出来
02
三种放手程度
只聊天、帮你搭、完全交给它自主执行,你选
03
中文场景友好
用中文提需求、看中文注释,是国内最早上的一批
适合谁 想在一个窗口里把项目做完的人;不习惯终端的人
注意 2026 年 8 月起,团队已并入字节的豆包体系
【Trae 能力 · 20 秒】 它适合:从零建项目、想控制放手程度、以及中文场景。 它最大的价值是给不习惯终端的人一个完整的环境。 补一个信息:2026 年 8 月,Trae 团队已经并入字节的豆包体系。

WorkBuddy

腾讯云 CodeBuddy 团队出品

不是编程工具,是给所有职场人的桌面 Agent

桌面工作台 能读本地文件 微信遥控
【WorkBuddy · 25 秒】 第四个要特别说明:WorkBuddy 不是编程工具,是腾讯的办公 Agent。 它最不一样的地方是能读你电脑里的本地文件,自己去整理、分析、做成东西。 右边这个手机是说:你在外面用微信发一句,家里电脑自己开工。 所以它面向的是不写代码的普通职场人。
WorkBuddy

它和聊天框差在哪

01
多个 Agent 并行
最多 8 个同时干不同的活,不是排队一个一个来
02
能在本地动手
直接读你硬盘上的文件、整理归类、提取数据做汇报
03
三档放手程度
只聊、直接干、先给计划再干,按任务复杂度选
适合谁 不写代码的职场人;要整理一堆文档和数据的人
注意 腾讯还有 CodeBuddy 和 QClaw,三个名字别混
【WorkBuddy 能力 · 20 秒】 三点:多 agent 并行、能在本地动手、三档放手程度。 适合不写代码的职场人,尤其是要整理一堆文档和数据的。 提醒:腾讯还有 CodeBuddy 和 QClaw,名字很像,但分工完全不同,别混。

DeepSeek
Harness

DeepSeek 出品 · 开源

一个开源的 agent 运行环境,什么都做成插件

桌面 App 网页界面 开放源代码
【DeepSeek Harness · 25 秒】 最后一个,DeepSeek 的 Harness。 它的思路和前四个都不一样:它把一切都做成插件,而且开源。 也就是说,能力不够就装一个插件;找不到合适的,直接跟它聊天让它给你造一个。 注意它和 DeepSeek 的模型是两回事 —— 模型是模型,这个是运行环境。
DeepSeek Harness

它为什么值得单独讲

01
开源,能自己改
代码公开,不满意可以自己动手,不用等厂商更新
02
能力靠插件长出来
定时任务、多 Agent、语音输入,都是装上去的插件
03
聊天就能造插件
不会写代码也行,说一句让它给你做一个
适合谁 喜欢自己折腾的人;不想被某一家厂商锁死的人
注意 目前还是公开预览版,不是正式版
【Harness 能力 · 20 秒】 三个理由:开源能自己改、能力靠插件长出来、还能直接用聊天造插件。 适合喜欢折腾、或者不想被一家厂商锁死的人。 提醒一句:它现在还是公开预览阶段,不是正式版。
