# 抖音 AI 科普课 · 课件工作区

给普通人看的 AI 科普短视频课件。横屏 16:9,自包含 HTML,离线可用。

## 目录

```
contract.md                  ← 课件契约。改课件前先读它
courseware/
  lesson-01.html             ← 第 1 讲:AI 公司和大模型是什么关系
  lesson-02.html             ← 第 2 讲:会自己动手的 AI(五个工具)
  lesson-03.html             ← 第 3 讲:模型这么多,到底该怎么选
  build.ps1                  ← 把 CSS / JS / 图标重新内联进所有 lesson-*.html
  assets/deck.css            ← 设计系统源文件
  assets/deck.js             ← 放映器源文件
  assets/logos/*.svg         ← 15 个官方品牌图标(内置,不走 CDN)
README.md                    ← 本文件
```

两个课件都是**自包含单文件**,CSS、JS、图标全部内联。
可以单独复制到任何地方双击打开。`assets/` 是**唯一真源**。

## 打开与放映

双击 `courseware/lesson-02.html` 即可。不需要服务器、不需要联网。
两讲操作完全一样:

| 输入 | 行为 |
|---|---|
| `→` / `空格` / `滚轮下` | 下一页 |
| `←` / `滚轮上` | 上一页 |
| 鼠标点击 | 左 15% 上一页,其余区域下一页 |
| `Home` / `End` | 首页 / 末页 |
| `F` | 全屏(录制前按这个) |

| `?` | 显示快捷键提示 |

用 `lesson-02.html#8` 可直接跳到第 8 页补录单页。

### 五张示意图是矢量的,不是图片

第 4/6/8/10/12 页的示意图是**内联 SVG 画出来的**,不是截图。

- 好处:矢量、放多大都清晰、不占体积、没有版权风险、不会过期
- 代价:它不是真实界面截图,是示意

如果你想要**真实截图**,可以在课件里换成图片:把截图放进
`courseware/assets/shots/`,然后在对应页把 `<svg class="diagram">…</svg>`
整段换成 `<img class="diagram" src="assets/shots/xxx.png" alt="…">`,
最后跑一次 `build.ps1`(它目前只内联图标,CSS/JS 之外不会自动内联图片,
所以图片要么保持相对路径,要么你手动换成 data URI)。

## 第三讲:有个活要干,该挑哪个模型

**按真实工作场景分,不按厂商的型号分类。**

核心论断:**大部分人其实不用挑模型** —— 你不是在挑模型,你是在某个 Agent 里干活,
工具默认配好的那个通常就够用。真正要挑的只有两种情况:工具弹出来让你选,
或者你要把 AI 接进自己的工作流。

| 4 | 五个真实场景总览 |
| 5 | 场景一 **纯对话、问问题** — GPT-6 Astra / Gemini 4 Argon / DeepSeek V4 Pro |

第 5–9 页版式是左右两栏:左栏是这类场景的**真实说法示例**(3 条,
例如「把这份报告变成 10 页 PPT」),右栏是这类场景该挑的**3 个具体型号**
(带厂商图标),底部一行写**落到哪个工具**。

### ⚠️ 三个必须保留的东西

1. **「五个场景」是课件自己搭的框架**,不是厂商官方分类,也不是业界标准。
   划法依据是「普通人在电脑前实际会遇到的活」。录制时请在口播里说明
   (第 4 页备注已写)。
2. **「大部分人不用挑模型」有前提**:仅当工具已经自动替你选好模型时成立。
   工具弹出模型选择、或你要接进自己的工作流时,这条不成立。第 3 页已把前提
   写在屏幕上,后续引用不要省掉。
3. **「快省 ↔ 准强」是旋钮,不是场景**。第一版第三讲把「量大要省钱」当成一个
   场景,被判不可用 —— 抽象维度观众对不上号。它现在是第 10 页那根轴。

## 改内容

- **改文案**:直接改 `lesson-0X.html` 里对应的文字。
- **改颜色 / 字号 / 版式**:改 `courseware/assets/deck.css`,然后运行:

  ```powershell
  powershell -ExecutionPolicy Bypass -File build.ps1
  ```

- **改图标**:替换 `courseware/assets/logos/<key>.svg` 后同样跑 `build.ps1`。
  它会自动处理目录下**所有** `lesson-*.html`。

`build.ps1` 只替换三段内容(CSS、JS、图标占位符),**不动课件正文**,可反复运行。
**忘了跑这一步,你在 assets 里的改动不会生效。**

## 出问题时先看这里

| 症状 | 原因 |
|---|---|
| **所有内容按文档流堆在一起、没有分页** | CSS 没生效。文件被改回用 `<link>` 引外部 CSS 了。跑一次 `build.ps1`。 |
| **公司页 / 工具页左右两栏上下堆起来** | 页面级版式被 `.slide.is-active` 的 `display:flex` 压掉了。现在的版式都挂在独立元素上(`.co-main`、`.tool-main`),不要再往 `.slide` 上加 `display`。见契约 8.2。 |
| **图标位置是空白** | `assets/logos/<key>.svg` 缺失,或占位符写法不对(必须是 `<!--LOGO:key--><!--/LOGO-->`)。 |
| **build.ps1 报语法错或输出乱码** | .ps1 丢了 UTF-8 BOM。Windows PowerShell 5.1 会把无 BOM 的脚本按 GBK 解码。见契约 8.3。 |
| **翻了页但控制台报 `replaceState` 错误** | `file://` 下 Chrome 禁止这个 API,已 try/catch 吞掉。若又出现说明 JS 被换回旧版。 |

## 已知事项(不要修,先读)

**内容层面**
- 五家公司的工具覆盖是有结构的:Codex / Claude Code / Trae 是**编程 agent**,
  WorkBuddy 是**办公 agent**,DeepSeek Harness 是**开源的运行环境**。
  三者不是同一类东西,课件第 3 页专门把这条线拉出来讲。
- **腾讯没有出现在第一讲的 9 家公司里**,但第二讲有腾讯的 WorkBuddy。
  如果要保持两讲一致,第一讲可能该补上腾讯(混元)。**这是待你决定的缺口。**
- 型号与产品信息截至 **2026-10**。按契约第 9 条每季度复检一次。

**技术层面**
- **brand 色值已全部核实**,取自 simple-icons 官方库或公司官网 logo 本身:
  其中 WorkBuddy 的 `#0EC8A9` 是从它官方 logo 的渐变里取的。
- **xAI 与月之暗面的官方品牌色都是纯黑**,图标底看起来一样 —— 这是事实。
- **Codex 用的是 OpenAI 的标记**,因为在官方图标库里 Codex 没有独立图形。
- **WorkBuddy 的图标**是从官网 logo 里提取的白色字形(SVG 里形状本身溢出视口、
  靠 viewport 裁切,与官方原图行为一致)。
- **布局未做浏览器实测**:没有可用浏览器环境,版式按算式核对。
  最需要你亲眼确认:第一讲第 14 页名录网格、第二讲第 4/6/8/10/12 页示意图比例。
