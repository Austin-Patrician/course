## 1. 你说的两个问题,诊断如下

### 「感觉不到区别」

这是真的,而且有具体原因。上一版十个工具页**共用同一套骨架**:

```
[品牌图标]        │  ┌────────────────────┐
工具名 84px       │  │ 窗口矩形 + 圆角胶囊  │   ← 五个工具都是这张图
谁做的 34px       │  └────────────────────┘
一句话定位 44px   │
```

五个示意图全部由同样的「窗口矩形 + 胶囊方块」拼成,尺寸、位置、颜色规则都一样。
观众的视线拿不到任何「切换」的信号 —— 而这**恰好是这一讲唯一要讲的事**。

更糟的是,契约第 4.2 条当时**明确要求**「十个页面版式完全一致」。
所以这不是执行走样,是规则本身错了。v2.2 已经把这条规则改掉。

### 「没有根据当前真实情况讲述」

也是真的。上一版五个工具页里:

- **一个可核实的数字都没有** —— 观众无法判断谁在涨、谁在掉
- **没有「为什么是现在」** —— 不知道这批工具怎么冒出来的
- **没有「怎么选」** —— 结尾只有一句「写代码的选前三个」,那不是决策路径
- WorkBuddy 那一页尤其空:它是这一讲最值得讲的案例,却没有任何数据

### 2.4 WorkBuddy 那一页重写了(你点名的那条)

第 12 页「它凭什么一年做到第一」,三条按重要性排:

1. **零门槛** —— 下载、扫码、打开就用。Codex 和 Claude Code 光是把环境跑起来
   就能劝退一半人(网络、账号、权限)
2. **有现成技能** —— 内置 20+ 技能包;技能市场 7 万多个,两个月被下载 3000 万次。
   产品负责人原话:「用户不用懂什么是 Agent、什么是 tool,他只需要知道自己要什么。」
3. **人在外面也能干** —— 微信/企微/飞书发一句,电脑自己开工,结果发回聊天窗口。
   **这是 OpenAI 和 Anthropic 在国内复制不了的:IM 基础设施就是入口。**

数字:2026 年 6 月桌面端月访问 2097 万次,行业第一,比第二三名加起来还多;
腾讯 2026 Q1 财报里马化腾点名说它是「中国使用最广的效率智能体服务」;
活跃留存 >60%,付费留存 >80%。

**同时把代价写进去了**(不然不诚实):公测送 5000 积分拉来一大批人,
免费额度用完还有多少人愿意付费没有答案 —— 花旗研报写的是「最终命运尚待观察」。
所以它火得快,**不代表商业模式已被验证**。

另外补了一个第 11 页的口播点:Anthropic 也有对应的产品叫 **Claude Cowork**,
思路一样(同一套 agent 架构,但不用终端),只是国内复制不了微信这个入口。
这说明「办公 Agent」是全场共识,不是腾讯独创。

### 2.5 顺手修掉的一个 bug —— 这个比设计问题更严重

`deck.css` 里**从来没有 `.notes` 这条规则**。

`<aside class="notes">` 是 `.slide`(flex 容器)的子元素,默认 `display:block`,
于是**每一页的口播备注都被真的渲染在幻灯片底部**(深色 16px,紧贴 `.main` 下面),
又被 `#stage{overflow:hidden}` 裁掉大部分 —— 只露出最上面一行。

**也就是:备注文字会被录进画面。** 三个课件全部中招。

已修:

```css
.notes{ display: none; }
```

修完的连带好处:每页多回 40px 纵向空间,`.main` 现在能真正撑到底。
已在 `contract.md` 8.4 记档,别删这条规则。
